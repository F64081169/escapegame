# 已讀未回

攻略逃避型人格戀愛模擬器。女性視角乙女遊戲，分成三部：

| 篇章 | 內容 | 結局 |
| --- | --- | --- |
| 第一部　戀愛線 | 凌晨兩點撿到受傷小貓，遇見只會回「嗯」的獸醫江默。從已讀不回、消失三天，一路到冬至告白。 | 6 |
| 第二部　婚後線 | 婚後三年：停車場的二十五分鐘、回他嘉義老家過年、冷戰、急診室，以及東京的那一晚。 | 3 |
| 第三部　男方視角 | 同樣的日子，換成江默的手機。玩家決定每則草稿要「傳送」還是「刪除」；勇氣不夠時，拇指會停住。 | 2 |

## 怎麼玩

用瀏覽器打開 `index.html` 即可，不需要安裝或建置。

- 點擊畫面、空白鍵或 Enter：下一句
- 數字鍵 1–4：選擇選項
- 右上角：對話紀錄、自動、快轉、選單（設定文字速度、隱藏數值、結局收集）
- 每章開頭自動存檔，存在瀏覽器的 localStorage

## 數值

- **親密**：他願意靠近妳多少
- **逃跑**：滿 100 他就會消失（第一部「查無此人」）
- **自我**：太低會變成「焦慮迴圈」；照顧好自己也是攻略的一部分
- **勇氣**（第三部）：傳送草稿需要的勇氣；每次嘗試傳送都會增加

## 檔案

- `index.html`：版面與樣式
- `engine.js`：劇本直譯器、對話框、手機聊天、草稿機制、存檔與結局
- `scene.js`：場景背景、道具與粒子效果（雨、燈光、煙火）
- `story/`：劇本，`p1*` 戀愛線、`p2*` 婚後線、`p3*` 男方視角與結局資料

劇本是純資料：`{n:'旁白'}`、`{s:'jm', t:'台詞'}`、`{th:'心聲'}`、`{c:[選項]}`、`{msg:'them', t:'訊息'}`、`{draft:'草稿', need:勇氣}` 等，新增劇情只需要改 `story/`。
